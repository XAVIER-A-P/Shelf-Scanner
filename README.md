# 📚 Shelf Scanner
**Production-Grade AI Book Discovery Pipeline**

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.100+-green.svg)](https://fastapi.tiangolo.com)

Shelf Scanner is a mobile-first, AI-powered web application that turns a simple photo of a bookshelf into a personalized reading list. 

Built with a focus on **systems engineering and production reliability**, this project demonstrates a complete AI product lifecycle—handling real-world constraints like multimodal model latency, API cost management, resilient fallback strategies, and frictionless user onboarding.

---

## 🎯 What It Does

Ever stared at a shelf of books at a sale or a friend's house and didn't know where to start? Shelf Scanner solves this. 
Users simply snap a photo of a bookshelf using their mobile device. The system's AI pipeline extracts the text from the book spines, cross-references them to generate intelligent reading recommendations, and provides direct links to purchase—all without requiring the user to create an account.

## ✨ Key Features

* **Zero-Friction Onboarding:** Device-based session management utilizing long-lived HTTPOnly cookies. No user accounts, passwords, or login screens required.
* **Resilient AI Vision Pipeline:** Primary execution via OpenAI's GPT-4o Vision, with an automated, low-cost fallback to Google Cloud Vision OCR if the primary model fails or times out.
* **Intelligent Recommendations:** Context-aware book scoring and personalized "hooks" generated by GPT-3.5-Turbo.
* **Lightning-Fast UI:** Built using HTMX and Jinja2 templates for a Single Page Application (SPA) feel without the heavy JavaScript bundle payload.

## 🛠️ Technology Stack

**Backend & Core API**
* **Framework:** Python / FastAPI (Fully Asynchronous)
* **Database:** PostgreSQL (via SQLModel / SQLAlchemy)
* **Caching & Queue:** Redis (via upstash/redis)
* **Storage:** AWS S3 (boto3)

**Artificial Intelligence**
* **Primary Vision:** OpenAI GPT-4o Vision API
* **Fallback OCR:** Google Cloud Vision API
* **Recommendation Engine:** OpenAI GPT-3.5-Turbo API

**Frontend**
* **Templating:** Jinja2
* **Interactivity:** HTMX
* **Styling:** Tailwind CSS

**Infrastructure & DevOps**
* **Containerization:** Docker
* **Deployment target:** Render / Railway / AWS App Runner

## 🏗️ Project Architecture

The system is designed as a synchronous flow with asynchronous I/O to handle long-running LLM requests without blocking the main server thread.

```mermaid

    FastAPI -->|3A. Primary Vision| GPT4[GPT-4o Vision]
    GPT4 -- Success --> RecEngine[Recommendation Engine]
